# Lucide probe — `lucide_icons_flutter 3.1.17`

Disposable, isolated compatibility probe. It proves that the third-party
`lucide_icons_flutter` package at the **exact** version `3.1.17` resolves on
the pinned Flutter 3.47.2 toolchain and that every one of the 34 KuikChat
icons compiles as `IconData`, with no package-internal `IconData` subclass.

This is **verification tooling only** — it is not production code and does not
change the production `mobile/` dependency (`lucide_icons: ^0.257.0`) or its
seven import paths.

## Files

- `pubspec.yaml` — declares `lucide_icons_flutter: 3.1.17` (exact, no caret).
- `lib/icon_probe.dart` — the 34 required `LucideIcons` symbols as `IconData`.
- `pubspec.lock` — generated by the pinned CI toolchain; committed after the
  first green probe run (mirrors the `mobile/pubspec.lock` workflow).

## Run

```bash
cd tools/probes/lucide_icons_flutter_3_1_17
flutter --version
dart --version
flutter pub get
flutter pub deps --style=compact
flutter analyze lib/icon_probe.dart
```

The dedicated CI job (`lucide-probe` in `.github/workflows/mobile-ci.yml`)
performs the full sequence and fails if `3.1.17` does not resolve, if any
source class extends `IconData`, or if any of the 34 icons fails to compile.

## Gate

If `3.1.17` cannot be resolved, the job fails and the exact resolver output is
reported. No other version is substituted silently.
